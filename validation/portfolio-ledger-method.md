# 不复权持仓账本：13 个交易日的逐日核算

这是**真实历史行情、真实权益公告、假设持仓和模拟成交**的工程核对，不是用户实际账户流水。短区间不能证明月度再平衡更有收益。本例不调仓反而比调仓多 180.62 元。

| 核对项 | 结果 |
| --- | --- |
| 起点（2025-06-16 收盘） | 长白山 1,000 股、高测股份 2,000 股、现金 5,000 元；总资产 59,090.00 元 |
| 现金分红 | 两笔税前实收合计 441.50 元 |
| 转增上市 | 高测股份 800 股 |
| 权重信号 | 6 月 30 日收盘，各股目标 45%，其余留现金 |
| 模拟成交 | 7 月 1 日开盘：卖长白山 200 股，买高测股份 1,186 股；两笔交易费用合计 13.96 元 |
| 终点（2025-07-02 收盘） | 股数 800 / 3,986，现金 4,591.22 元，总资产 **65,728.88 元**；不调仓基线 **65,909.50 元** |
| 逐日核对 | 两个行情源 112 个 OHLC 值一致；13 日组合净值最大差额 **0.00 元** |

**来源。** 腾讯 day 原价和东方财富 fqt=0 原价，含评价期之前一个交易日，共每股 14 根日线。两源成交量单位可能不同，本版只用有无成交量判断是否保守跳过开盘委托。每个来源的完整请求、原始行以及 SHA-256 保存在[冻结行情样本](../tests/fixtures/portfolio-ledger-raw-202506.json)。持仓登记日、除息日和支付/上市日来自[长白山实施公告](https://static.cninfo.com.cn/finalpage/2025-06-13/1223859419.PDF)及[高测股份实施公告](https://static.cninfo.com.cn/finalpage/2025-06-20/1223935346.PDF)。

**记账。** 总资产 = 可用现金 + 已上市股份按原价市值 + 应收股息 + 待上市股份按原价估值。登记日收盘确定获配数量；除权日建立应收；支付日收盘现金转可用；新增流通股上市日可卖。起点已有股数和现金按首日收盘快照解释。若以前登记的权益尚未结清，须提供该登记日实际持股数或提早起点。产生零碎股时，需真实整数获配结果。未模拟卖出补扣的个人红利税。

**调仓。** 月末或季末收盘使用当时的总资产、收盘价定目标数量。下一交易日开盘先卖后买，按交易日期/板块约束申报单位、单笔上限、涨跌停、印花税和过户费；总现金不足时按同一比例缩减有效买单，取整余款留现金。示例佣金万三、最低 5 元、单边滑点万五。交易价包含滑点模型，不能当作实际券商成交；开盘涨停买/跌停卖、成交量缺失或零、跨除权日旧指令均保守跳过。基线使用相同初始账户、行情、权益和费用假设，之后不再调仓。

**独立性。** 生产 JS 使用腾讯价格和公司行为/历史规则模块；独立 Python 用东方财富原价、从公告提取的登记和发放日期、十进制定点金额以及本例 2025 年适用的费税复算。脚本逐日比较两条净值、现金、收盘持股、T+1 可卖，另比较成交股数、成交价、每项费用和权益事件。实际样本中除权/支付/上市同日；另有确定性用例验证延付和延迟上市的应收估值与可用性。

在仓库根目录运行：

    node --test tests/portfolio-ledger.test.cjs
    python3 tools/verify-portfolio-ledger.py

第二条默认离线读取冻结样本。如需重新请求原始行情并更新报告，运行 python3 tools/verify-portfolio-ledger.py --refresh --write-report；两个原价来源有一项不符即停止。逐日数字见[独立对账结果](portfolio-ledger-real-202506.json)。
