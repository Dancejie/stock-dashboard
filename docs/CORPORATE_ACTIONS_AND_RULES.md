# 公司行为与历史交易规则

**数据核对日：2026-11-10。** 单股策略仍在输入的价格序列上研究信号。选择历史交易规则只改变交易约束与费用；它不会把前复权价格变成真实股数账本。组合公司行为账本必须使用明确标记的 **不复权（raw）** 日线，不能在前复权价格上再加现金红利或送转股。

例如，登记日收盘持有高测股份 1,000 股，则应享现金 180 元，新增 400 股。只要登记日获权，即使除权日起卖出原有股票，已确定的权益也不会归零。反之，除权日才买入的股票不享受本次分派。若支付日或新股上市日晚于除权日，未到账现金及未上市股份可计入经济净值，不应提前列为可用资金或可卖股。公告只给日期，不证明当天开盘前已经可用；执行时点应以账本建模约定及券商记录为准。

这里没有完整市场数据订阅。预置数据仅声明上述股票和日期范围，且只核普通流通股分红和送转。不涵盖配股认购、缩股、换股合并、限售股、境外持有人预扣税、个人按持有期在卖出时补扣红利税或所有特殊公司行为。转增后不能整除的账户获配数可能依登记结算结果分配，不应直接四舍五入冒充实际持股。

### 来源与复核

1. 以股票代码及巨潮发行人 ID 查询全量披露标题（不依赖单一分红筛选接口）。两只沪股查询 2025-05-01～07-02，三夫户外查询 2026-04-01～11-10，共返回 20、22、74 条。人工筛查权益相关候选，并以最终实施公告核对每股金额、登记、除权、到账及上市日期。高测股份可转债转股价调整不构成普通 A 股股东的第二次权益。
2. [公开事件 JSON](../fixtures/corporate-action-books.json) 用于复现或参考导入，[归档索引](../fixtures/corporate-action-verification.json) 列出候选标题和四份 PDF 的完整 SHA-256。摘要核验可发现文件变化，不能替代阅读公告或独立确认区间完整性。
3. 在仓库根目录运行 `python3 scripts/verify-action-filings.py --output /tmp/filings.json --pdf-dir /tmp/public-filings`。脚本重新查询披露目录、下载发行人原件并比对 SHA-256；所有请求只读公开信息，不需要证券账户。网站服务不可用、公告被替换或发现新增实施公告会报错，不自动覆盖本地数据。

### 导入接口

浏览器提供 `StockCorporateActions.listCoverage()`、`getBook(symbol,start,end,importedBook?)`。导入使用上述 JSON **数组中的单个对象**；外层为 `symbol,coverageStart,coverageEnd,source,events`，每个事件需单独填写 `id,symbol,title,recordDate,exDate,cashPerShare,sharesPerShare,payDate,shareListingDate,source`。没有现金时 `cashPerShare:0,payDate:null`；没有送转时 `sharesPerShare:0,shareListingDate:null`。来源为公开 HTTPS 链接；`shareKind` 可区分资本公积转增、送红股。不得用“方案/预案”的预期日期替代已实施公告。

区间跨过声明覆盖边界会抛错；缺书与“已覆区间内无事件”是两种状态。已在区间前登记、区间内尚待结算的事件保留，须查清期初原持仓和应收项。外部导入仅做格式校验，一律标为用户核对，即使它自带 `verified:true`。本机运行不需要网络访问分红服务。

## 历史规则模式

`StockHistoricalRules.resolve(symbol,date,context?)` 覆盖 2016-01-01～2026-11-10 期间的沪深人民币普通 A 股；科创板自 2019-07-22。日期按成交日中国本地 YYYY-MM-DD 传入，不按信号日。采用当前以前已核实的规则版本，到期后应重新核实交易所公告再扩展。

开盘撮合按限价委托约束估算。历史模式观察到开盘就处于不利涨跌停边界时保守拒绝，不借用后来盘中打开涨跌停的信息模拟早盘成交；这不等于交易所一定无法成交。真实停牌、开盘集合竞价的可成交数量、盘口排队及市场冲击无法从日线恢复。不同券商费用展示可能将过户费纳入佣金，使用历史模式应确保填写的佣金不含已单列过户费，避免重复计费。

单股使用 `StockQuant.run(bars,strategy,params,{symbol,ruleMode:'historical',adjustment:'qfq'|'raw',ruleContext:{byDate:{...}}})`；逐日状态可传 `{riskWarning:true,listingTradeDay:3,listingDate:'YYYY-MM-DD'}`。风险警示历史、IPO、退市整理、复牌和除权参考价不能从今天的简称倒推。缺省按普通已上市股票计算并提示；已说明但不支持的特殊状态或日期直接拒绝。原始日线可用 `limitReferencePrice/limitUp/limitDown` 明确交易所参考价；复权序列仅按比例近似边界。单股仍是收益研究口径，不逐笔取到分、不抵扣个人红利税。真实组合账本使用 raw 并按其账户模型记账。旧的固定规则模式不变。
